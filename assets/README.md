# Logo assets

`logo.svg` and `logo.png` (512 × 512 transparent PNG) use the libtmux library
tile-and-cog geometry with Raku blue `#0000fb`.

Exports and renderer: [libtmux/assets, pinned Raku revision][assets]
([artwork PR](https://github.com/libtmux/assets/pull/7)). Palette source:
[GitHub Linguist, pinned revision][linguist]. Light and dark social cards live
upstream in [the verified query update][cards].

Use the pinned upstream artwork renderer when regenerating exports. `logo.svg`
is the editable library asset.
